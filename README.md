# Cursor Eye

**Live:** https://vishnuvsdevtech.github.io/cursor-eye/

A page that watches back. An eye that tracks the pointer on a spring, blinks on an irregular timer, dilates with pointer speed — and looks away if you stare at it.

**How:** The fourth behaviour is the one that changes how people behave: hold the pointer within 110px for 2.5s and the iris rotates to the far edge and blinks. Pupil dilation with speed is a genuine autonomic response repurposed as a UI signal.

**What it is not:** Uncomfortable for three seconds, then charming.
